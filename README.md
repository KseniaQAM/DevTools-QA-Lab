# DevTools QA Lab

Учебный QA-проект по функциональному тестированию веб-приложения с использованием Chrome DevTools.

## О проекте

DevTools QA Lab — учебное веб-приложение, предназначенное для практики функционального тестирования и анализа взаимодействия клиентской и серверной частей приложения.

В рамках проекта проведено функциональное тестирование основных разделов приложения. Для проверки поведения системы и анализа обнаруженных проблем использовались инструменты Chrome DevTools.

## Цель тестирования

Проверить функциональность веб-приложения DevTools QA Lab на соответствие ожидаемому поведению, выявить дефекты и задокументировать результаты тестирования.

## Область тестирования

В рамках проекта тестировались следующие разделы приложения:

- авторизация;
- каталог товаров;
- корзина;
- профиль пользователя;
- настройки.

## Выполненная работа

В ходе проекта были выполнены:

- изучение функциональности приложения;

## Запуск приложения

Для локального запуска приложения необходимы:

- Windows 10/11;
- Python 3.9 или выше;
- Google Chrome.

Порядок запуска:

1. Скачать или клонировать репозиторий.
2. Перейти в папку `application`.
3. Запустить файл `run_local.bat`.
4. Открыть в браузере адрес `http://localhost:8000`.

Для остановки сервера нажать `Ctrl + C` в окне терминала.

**Особенности работы приложения:** данные хранятся в памяти сервера. После перезапуска сервера состояние приложения сбрасывается.
